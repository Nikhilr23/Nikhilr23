## Featured work

### 🏥 NoShowCalc
**Healthcare operations · Live**

A browser-based calculator for outpatient practices to estimate the revenue opportunity affected by no-shows and late cancellations using practice-level assumptions only.

**Why I built it:** missed appointments affect both access and revenue, but the first useful version did not need patient-level data or a backend.

[Live app](https://nikhilr23.github.io/noshowcalc/) · [Repository](https://github.com/Nikhilr23/noshowcalc)

### 💰 ProfitQuote
**Small-business pricing · Live**

A profit-aware pricing calculator for cleaning businesses that calculates true job cost, estimated profit, gross margin, and the minimum quote required to reach a target margin.

**Why I built it:** many small service businesses price from intuition or market averages without seeing whether the job is actually profitable.

[Live app](https://nikhilr23.github.io/profitquote/) · [Repository](https://github.com/Nikhilr23/profitquote)

## How I build

**1. Define the decision**  
Start with the exact question the user is trying to answer.

**2. Make the logic visible**  
Prefer transparent formulas and assumptions over unnecessary black-box automation.

**3. Keep the first version small**  
Avoid accounts, databases, integrations, or AI unless they improve the core job.

**4. Validate before adding complexity**  
Use real feedback to decide what deserves a second version.
